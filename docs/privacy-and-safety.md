# Privacy & Safety

This repository is intentionally sanitised for public portfolio use.

## Excluded

The repository does **not** include:

- Original client event logs
- Real company/user/workflow identifiers
- API tokens or API keys
- Client endpoint configuration
- Production URLs
- Raw reports containing credentials
- Student IDs
- Internal screenshots containing client information

## Included

Only the following are included:

- Synthetic demo event data
- Generic analytical code
- Portfolio documentation
- Safe API integration placeholders

## Public GitHub Recommendation

Before publishing, review the repository history as well as the current files.

Deleting a secret from the latest commit does not remove it from previous Git history.
